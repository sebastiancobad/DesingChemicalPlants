# Remotion Video Project

A video project built with [Remotion](https://remotion.dev/).

## Getting Started

### Install Dependencies

```bash
npm install
```

### Start the Studio

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Upgrade Remotion

```bash
npm run upgrade
```
