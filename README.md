# Designing Chemical Plants

A project for the design and simulation of chemical plants and processes.

## Overview

This repository contains tools and resources for chemical plant design, including:

- Process flow diagrams and modeling
- Equipment sizing and selection
- Material and energy balances
- Cost estimation

## Getting Started

### Prerequisites

- Python 3.9+
- pip

### Installation

```bash
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
